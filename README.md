# powerlog
This is a hosting app for Power-Z KM003C power meter
PowerLog 充电功率记录仪 v1.2.0
================================
<img width="1843" height="1209" alt="image" src="https://github.com/user-attachments/assets/e251a239-f21f-4f9e-86dc-6f8ef52d7676" />

适用设备：POWER-Z KM003C USB-C 功率计
系统要求：Windows 10 / 11 64 位
无需安装，解压/复制后双击 PowerLog.exe 即可运行。

本压缩包内有两个版本，功能完全相同：
  PowerLog.exe                 单文件便携版，双击即用（首次启动约 2-3 秒）
  PowerLog_文件夹便携版.zip      解压后运行里面的 PowerLog.exe，启动更快
  若单文件版被杀毒软件误报或拦截，请改用文件夹版。

界面预览：见 界面预览.png
报告示例：见 示例报告.html（双击用浏览器打开）


一、准备工作
------------
1. 把 KM003C 的 PC/监控口用数据线连到电脑，另一个口串接充电器与被测设备。
2. 完全退出 Power-Z Lab / PDM / Mtools（包括右下角托盘图标）。
   这些软件会独占 KM003C 的虚拟串口，导致本工具打不开设备。


二、开始记录
------------
1. 双击 PowerLog.exe。左上角出现绿点并显示 “KM003C · 035675  已连接” 即成功。
2. 选择采样间隔（默认 1s，与原软件一致）。
3. 只看不记：点击“查看数据”（快捷键 V），实时显示电压/电流/功率，
   后台缓存数据但不写文件。
   · 点“停止”或按 Esc：直接丢弃缓存，不生成 CSV/报告。
   · 查看过程中点“开始记录”（或按空格），会弹窗询问：
       - 重新抓取：丢弃缓存，从这一刻开始正式记录
       - 保留抓取：把查看期间的数据一起并入本次记录
4. 直接记录：点击“开始记录”（或按空格），从当前时刻开始写 CSV。
5. 记录中可随时点击“停止”或再按空格结束。

自动停止条件（快捷键 C）：
  · 勾选要监测的项目：电压 / 电流 / 功率
  · 选择“低于 / 高于”，填写阈值（例如 电流 低于 0.05 A）
  · 填写“持续”秒数（例如 60 秒），条件连续满足这么久才停止
  · 判定方式可选“全部满足”或“任一满足”
  · 还可设置“最长记录”分钟数（0 表示不限）
  · 勾选“停止后自动保存 CSV 并生成 HTML 报告”

停止后会自动在 exe 同目录的 records 文件夹生成：
  充电记录_YYYYMMDD_HHMMSS.csv    数据表（Excel 可直接打开）
  充电记录_YYYYMMDD_HHMMSS.html   图文报告
若 exe 所在目录不可写（如放在 Program Files），会自动改存到
“文档\PowerLog\records”。


三、界面说明
------------
· 顶部三个方块 VBUS / IBUS / PWR：控制曲线上显示哪些项目。
  注意：无论显示与否，后台始终记录全部数据，CSV 里也全都有。
· 时间窗口：1 分 / 5 分 / 30 分 / 全部。
  鼠标滚轮缩放，按住左键拖动平移，双击恢复自动跟随。
· 鼠标悬停在曲线上可查看该点的时间和数值。
· 只显示一个项目时，坐标轴自动切换为该项目的单位。
· 电流/功率显示的是绝对值（与 KM003C 屏幕一致），不会出现负数。
· SUB 卡片“方向”表示真实电流方向：
   母→公  电流从母口流向公口
   公→母  电流从公口流向母口（充电器插在公口时常见）
  大数字和曲线都是绝对值，方向只作参考；CSV 里另有“原始电流(A)”保留符号。
· 底部状态栏：累计时间、容量 Ah、能量 Wh、采样点数、平均功率。
· “查看数据”（快捷键 V）：只实时显示、不保存；转记录时可选保留或丢弃缓存。
· “坐标轴”（快捷键 A）：三条纵轴固定从 0 开始，只有最大值动态扩展；
  可手动填写电压/电流/功率最大值，填了以后固定不变（留空或 0 = 自动）。


四、报告内容
------------
· 最大功率 / 最大电压 / 最大电流（含发生时刻）
· 平均功率 / 平均电压 / 平均电流
· 充入能量 Wh、充入容量 Ah
· 电流方向
· 记录时长、采样点数、电流方向
· 电压 / 电流 / 功率曲线
· 统计明细、电压平台分布、记录信息
报告是单个 HTML 文件，图片内嵌，可直接发送、打印或另存为 PDF。


五、常见问题
------------
Q：提示“未找到 POWER-Z 设备”？
A：确认线插在 KM003C 的 PC 口，换一个 USB 口重试；
   并确认 Power-Z Lab / PDM 已完全退出。

Q：提示“无法打开串口 COMx”？
A：虚拟串口被官方软件占用。退出官方软件（含托盘）后，
   点击左上角设备状态重试。

Q：数值一直是 0？
A：空载时电流接近 0 属正常，接上手机/负载后才有功率。

Q：为什么电流是正的，但“方向”显示 公→母？
A：新版（v1.1.0）起，电流/功率统一按绝对值显示，和 KM003C 屏幕一致；
   “方向”只表示真实电流方向，不影响功率大小。
   例如充电器插在公口、手机接母口时，方向就是 公→母。

Q：自动停止条件里的“电流低于 0.05A”在反向接法下还准吗？
A：准。条件按绝对值判断，接法方向不影响。

Q：为什么坐标轴不是从 0 开始了？
A：v1.2.0 起三条纵轴固定从 0 开始，只有最大值随数据扩展。
   点“坐标轴”可以手动固定最大值，适合固定量程对比。

Q：查看数据时忘了点开始记录，数据还在吗？
A：不在。查看模式只缓存、不写文件；点“停止”或按 Esc 会直接丢弃。
   如果想把查看期间的数据留下，请在停止前点“开始记录”并选“保留抓取”。

Q：能采样更快吗？
A：可选到 20 Hz。本工具通过串口轮询读数，20 Hz 已足够覆盖充电曲线。

Q：想先看看界面？
A：运行 PowerLog.exe --demo 进入演示模式（模拟一条完整 PD 充电曲线），
   不影响真实设备。


六、数据与隐私
--------------
· 工具只读取 KM003C 的 ADC 数据，不修改设备任何设置。
· 不联网、不上传任何数据，所有文件都保存在本机。
· 记录过程中 CSV 会持续写入，即使程序意外退出，已记录数据也不会丢失。
